# Changelog

## v0.1.0 - 2026-09-11
First public release. Scope per docs/MEASUREMENT_CONTRACT.md; the Guangzhou
holdout (docs/superpowers/research/) shaped the regime guard below.

### Added
- geometry: CRS-declared cleaning (source_crs required), index-preserving
  lineage, stdlib GCJ02/BD09 transforms, split hull APIs (no double projection)
- sanity: exact-NN fly-outlier detection with 10 km absolute floor,
  fail-closed user adjudication
- band: CA reference band, single BHH constant BETA=0.7124, versioned
  heuristic policy envelopes (never a statistical CI), provenance-tagged
  circuity, degenerate and small-sample guards
- report: preassess() five-gate state machine; dense-revisit regime
  (visits/store > 2.5) REFUSED rather than miscalculated - single-hull axiom
  falsified on the 10-line Guangzhou holdout
- terrain: city -> circuity prior classifier; CLI; 44-test stdlib suite;
  CI 3.9-3.13; nightly synthetic throughput gate (baseline-relative)
